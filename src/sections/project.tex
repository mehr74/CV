\section{Projects}
    \citembullet \textbf{Cequence Obseverability Stack} \\*
    \textbf{Role:} DevOps Engineer \\*
    \textbf{Description:} In this project, we built an observability stack from the ground up to monitor all components across both pre-production and production environments, ensuring complete visibility into application performance. Our goal was to efficiently manage heavy loads of logs and metrics while optimizing dashboards for the best user experience. We focused on making the information clear, actionable, and easy for both developers and operations teams to understand and act upon. Additionally, we implemented custom alerting systems tailored for the operations team, ensuring they receive timely and accurate alerts for both application and server-related issues. This setup not only improved proactive incident response but also streamlined monitoring and troubleshooting processes for the entire organization.
    \\*
    \textbf{Tools:} Kubernetes, Ansible, Helm, ArgoCD, Terraform, Grafana, Prometheus, Alertmanager, Loki, Thanos, HAProxy
    \citembullet \textbf{NexVision incident management} \\*
    \textbf{Role:} DevOps Engineer \\*
    \textbf{Description:}  In this project, we developed an automated pipeline for building applications and plugins to enhance the developer team’s workflow. We utilized AWS CDK to create a full-stack solution, enabling the creation of servers and all necessary components with a single command. Additionally, we integrated AWS Cognito for user management, enabling Single Sign-On (SSO) for Grafana login, simplifying access control and improving the security of our monitoring platform.
    \\*
    \textbf{Tools:} AWS, Docker, GitHub Action, Grafana, Prometheus, Loki, Alertmanager, HAProxy 
    \citembullet \textbf{Vipar Monitoring Stack} \\*
    \textbf{Role:} DevOps Engineer \\*
    \textbf{Description:} In this project, we used Ansible to automate the installation of Node Exporter across over 70 Windows and Linux servers, collecting key metrics for Prometheus monitoring. We created custom dashboards to provide a comprehensive view of all servers and their behaviors, ensuring full visibility into system performance. Additionally, we implemented alerting rules to guarantee that the operations team receives notifications for any critical events, enabling quick and efficient response to issues.
    \\*
    \textbf{Tools:} Ansible, Grafana, Prometheus, Alertmanager
    \citembullet \textbf{Nphaze/Pfizer Observability Platform} \\*
    \textbf{Role:} DevOps/Observability Engineer  \\*
    \textbf{Description:} As part of the Optiop team engaged on the Nphaze project, deployed and operated an LGTM monitoring stack (Loki, Grafana, Tempo, Mimir) for both Nphaze and Pfizer with alert routing to increase observability and visibility across applications and infrastructure. We managed to migrated the client from a legacy Prometheus/Promtail/Node-exporter setup to an operational Mimir/Alloy/Loki deployment across all infrastructure. Monitored both EC2 and EKS infrastructure and the applications running on them. Investigated recurring application issues and delivered AI powered runbooks so teams could gain better insight into their own application issues, and built RCA dashboards tailored to each team’s needs.
    \\*
    \textbf{Tools:} Grafana, Loki, Tempo, Mimir, Alloy, Prometheus, Alertmanager, AWS EC2, AWS EKS, Argocd, Kubernetes, Linux
